# app-policies

Static home pages and privacy policies for small personal tools that use
Google OAuth, served with GitHub Pages at
https://shashankkarpal.github.io/app-policies/.

Google requires an app's home page and privacy policy to live on a domain the
developer controls before the app can leave Testing status. This repository is
that domain.

| App | Home page | Privacy policy |
|---|---|---|
| ESI push | [esi-push/](https://shashankkarpal.github.io/app-policies/esi-push/) | [esi-push/privacy.html](https://shashankkarpal.github.io/app-policies/esi-push/privacy.html) |

Plain HTML and one stylesheet; no build step, no scripts, no tracking.

MIT. Pages written by Claude (Anthropic) for a single maintainer.

ESI push privacy policy

Effective 4 October 2026

ESI push is a personal tool used by one person, its maintainer, to update Google Sheets spreadsheets he owns. This page explains what Google user data the tool touches and what happens to it.

Data the tool accesses

  • Through the Google Sheets API, the contents of the spreadsheets the user explicitly points the tool at. Nothing else in the Google account.
  • An OAuth access token and refresh token issued by Google, which let the tool act on those spreadsheets.

How the data is used

  • Spreadsheet contents are read only to find where new rows belong and to confirm that a write succeeded. New rows are written back to the same spreadsheet.
  • The OAuth tokens are stored in a single file on the user's own computer, readable only by that user's operating system account. They are never uploaded, logged or shared.

Sharing

No Google user data is sold, shared with, or transferred to any third party. There is no server, analytics, advertising or tracking of any kind. Data moves only between the user's computer and Google.

Limited Use

ESI push's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and deletion

The tool keeps no copy of spreadsheet data. The token file stays on the user's computer until the user deletes it. Access can be revoked at any time at myaccount.google.com/permissions, which makes the stored tokens useless.

Contact

Questions about this policy: open an issue at github.com/ShashankKarpal/app-policies.
